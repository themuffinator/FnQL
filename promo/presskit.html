An open-source engine for the Quake Live you already own.

FnQL is a modernized replacement engine for the retail Steam release of Quake Live. FnQL players join retail servers, retail players join FnQL servers, and demos, maps, the WebUI and Workshop content keep working. On top come GLx and Vulkan renderers, HDR, raw input with Quake Live's own mouse math, HRTF audio and a modern console.

Highlights

Retail first

Protocol 91, .dm_91 demos, BSP v47, factories, profiles, the retail WebUI, Steam integration and Workshop content.

Plays both ways

FnQL joins retail servers; retail clients join FnQL servers and get exactly what a retail server sends.

Modern rendering

GLx and Vulkan renderers with HDR, MSAA and supersampling, bloom, tone mapping, soft particles, liquids and fog.

See every player

Optional rim lighting and outlines in your own enemy and team colours, plus cel shading.

Real shadows

Shadow-mapped dynamic lights, and optional sun shadows from each map's own sky that players cast too.

Input that matches

Raw mouse with Quake Live's CPI scaling and acceleration; classic Quake3e and ioquake3 styles kept.

Spatial audio

OpenAL with HRTF, surround, reverb and occlusion, live device recovery and a software fallback.

Open game modules

The open-source FnQL-game modules run by default since 0.1.0.158, checked against retail by a zero-divergence lockstep harness.

Hardened server

Rejects hostile downloaded content, survives rcon edge cases and writes match stats as JSON lines without libzmq.

FAQ

Is FnQL official?

No. It is an independent project, not affiliated with or endorsed by id Software, Bethesda, ZeniMax Media or Valve.

Do I need to own Quake Live?

Yes. FnQL uses the game files from your Steam installation and ships none.

Is it a cheat? Can I be banned?

FnQL is an engine replacement with no cheating features. It authenticates through Steam's normal session tickets and never fakes them. It is unofficial, so server operators decide which clients they accept.

Which platforms are supported?

Official packages are the Windows x86 client and the Linux i686 dedicated server. Retail's client modules and WebUI are 32-bit Windows binaries, so there is no supported native Linux or macOS client for retail play.

Does it do ray tracing?

There is an experimental RTX renderer module whose native path covers a conservative subset of world geometry. GLx and Vulkan are the renderers to use.
